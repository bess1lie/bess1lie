## 👋 About

AppSec student, 17 — building **detection-first, scope-aware** security CLIs.

Focus: recon automation, API & GraphQL attack surface. Every tool is gated by `scope.yaml` — no payloads, no exploitation, open formats (`SQLite` / `SARIF` / `HTML`).

> `detection-only` `scope-aware` `open-source` · MIT

**gqlhunter** — GraphQL recon & risk. Introspection, `IDOR/BOLA` classification, schema diff, SARIF 2.1.0 + dashboard. `202 tests`
