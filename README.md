## Work

Building **detection-first, scope-aware** security CLIs — recon automation, API & GraphQL attack surface. Every tool is gated by `scope.yaml` — no payloads, no exploitation, open formats (`SQLite` / `SARIF` / `HTML`).

> `detection-only` `scope-aware` `open-source` · MIT

**apihunter** — REST API security CLI. OpenAPI discovery, auth auditing, `IDOR`/`CORS`/`rate-limit` heuristics. `243 tests · 86% coverage`
<br>
**bounthunt** — Recon orchestration `subfinder → dnsx → httpx → naabu → nuclei → katana`. Scope-gated, diff monitoring, dockerized. `91 tests`
<br>
**gqlhunter** — GraphQL recon & risk. Introspection, `IDOR/BOLA` classification, schema diff, SARIF 2.1.0 + dashboard. `202 tests`
