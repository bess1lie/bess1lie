## Selected Work

### [`apihunter`](https://github.com/bess1lie/apihunter)
REST API security testing CLI — OpenAPI discovery, authentication auditing, heuristic scanning (IDOR, CORS, rate limiting), multi-format reports (HTML/Markdown/SARIF), SQLite storage, scope-aware.

`Python` `Typer` `Rich` `HTTPX` `Jinja2` `PyYAML` `SQLite`

---

### [`bounthunt`](https://github.com/bess1lie/bounthunt)
Bug bounty recon orchestration — subfinder/dnsx/httpx/naabu/nuclei/katana pipeline, YAML scope guard with allow/deny, checkpoint/resume, diff monitoring, SQLite history, Dockerized.

`Python` `Typer` `Rich` `HTTPX` `Jinja2` `PyYAML` `SQLite` `Docker`

---

### [`gqlhunter`](https://github.com/bess1lie/gqlhunter)
GraphQL recon & analysis — 18-path discovery, introspection with depth control, risk classification (IDOR/BOLA), auth comparison, schema diff, SARIF 2.1.0 export, built-in dashboard, 202 tests.

`Python` `Typer` `Rich` `HTTPX` `aiosqlite` `Jinja2` `PyYAML` `GraphQL`
